# Fast civilian passenger aircraft research

This public repository studies one question: **what is the fastest practical civilian passenger airplane?**

The work is deliberately non-actionable and civilian. It uses public historical/commercial benchmarks, low-order simulations, literature reviews, and verification gates. It does not contain aircraft designs, detailed specifications, propulsion or construction guidance, trajectories, operating procedures, or weapon-related material.
